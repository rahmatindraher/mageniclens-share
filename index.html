Informasi seputar penggunaan mageniclens share.

Apakah file foto harus diunggah ulang ke server mageniclens? +

Sama sekali tidak. Sistem membaca pratinjau langsung dari folder Google Drive Anda sehingga tidak memakan ruang penyimpanan ganda dan struktur folder asli Anda tetap aman.

Bagaimana ketentuan akses perangkat antara akun Trial dan Lisensi Berbayar? +

Akun Trial Gratis aktif selama 7 hari khusus pada 1 perangkat pendaftaran pertama. Sedangkan seluruh paket lisensi berbayar (7 Hari hingga Lifetime) mendukung hingga 2 perangkat sekaligus dengan jatah perpindahan perangkat 3 kali setiap 7 hari.

Apakah klien perlu menginstal aplikasi untuk membuka galeri? +

Tidak perlu. Klien cukup menekan tautan singkat yang Anda kirimkan lewat WhatsApp, lalu galeri akan terbuka mulus di browser ponsel maupun komputer mereka.
